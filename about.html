About Messmate

Why we made it and how it works.

The Problem

In many hostels, students talk about bad food, poor hygiene or slow service only with friends. The feedback is not written anywhere, so the mess manager never sees it and nothing improves.

Our Solution

Messmate is a small website where a student can give feedback in less than a minute. The report page collects everything and shows the total feedback, the average rating and the low ratings, so problems are easy to find.

Built With

HTML

The structure of every page: headings, text, images, forms and tables.

CSS

Colours, layout and the look of the website, with a different theme for each page.

JavaScript

The form checking, the report numbers and saving the feedback in the browser.
